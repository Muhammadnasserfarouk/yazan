# نوم يزن

تطبيق ويب بسيط لمتابعة نوم يزن: نوم الليل، والقيلولات، ومرات الصحيان، والإجمالي اليومي، مع تحليل مناسب لسنّه وتذكير بمواعيد العلاج.

- بيشتغل من غير نت بعد أول فتحة.
- كل البيانات متخزنة على الموبايل نفسه (مفيش سيرفر ولا حساب). اعمل نسخة احتياطية من قسم «البيانات».

## التثبيت على الآيفون
1. افتح لينك التطبيق من Safari.
2. دوس زرار المشاركة، واختار «إضافة إلى الشاشة الرئيسية».
3. افتحه دايماً من الأيقونة.

## الملفات
- `index.html` التطبيق كله (HTML/CSS/JS من غير أي مكتبات).
- `sw.js` بيخلي التطبيق يشتغل أوفلاين.
- `manifest.webmanifest` و `icons/` لأيقونة الشاشة الرئيسية.

عند تعديل أي ملف، غيّر `VERSION` في `sw.js` عشان الموبايل ياخد النسخة الجديدة.
